# Business Model Summary (Annex A template)

| Field | Response |
|---|---|
| Problem | Rural Zimbabwe lacks affordable broadband; meanwhile UHF DTT spectrum sits idle most of the day across most of the country, and POTRAZ has no system to safely open it to secondary use. |
| Primary user | POTRAZ (spectrum authority/operator of the system) and, downstream, rural community internet service operators / anchor institutions (schools, clinics) using the opened spectrum. |
| Beneficiary | Rural residents in underserved communities gaining broadband access; POTRAZ, gaining continuous AI-driven spectrum visibility instead of static allocation tables. |
| Customer or payer | Primary pilot funding: POTRAZ / AI4I milestone-based implementation support. Longer-term: institutional licensing -- POTRAZ operates the platform as national spectrum-management infrastructure; rural ISPs/community networks pay a nominal access fee or operate under a public-good/donor-funded model for anchor institutions (schools, clinics). |
| Value proposition | Continuous, verifiable spectrum-occupancy intelligence instead of periodic manual monitoring; a safe, auditable pathway to open idle spectrum for rural broadband without new licensing rounds. |
| Revenue or funding model | Public-good / institutional licensing hybrid: POTRAZ operates and funds the core platform (regulatory infrastructure); rural connectivity operators using opened channels may pay a small access/coordination fee once past pilot stage, following the anchor-institution model Microsoft's Airband pilots used in Kenya, Ghana and Namibia. |
| Cost drivers | Sensing-node hardware and maintenance, edge/cloud compute for the ML model, pilot-site connectivity build-out, field verification/compliance testing, personnel. See `../MASAISAI_AI4I_Proposal_Development.pdf` Section 5 for the itemised estimate. |
| Partnerships | POTRAZ (regulator, data/rules source, regulatory sandbox), NUST (institutional home, technical supervision), a pilot anchor institution (school or clinic in the first pilot community), ZCHPC (compute environment per Section 3 of the proposal). |
| Pilot market | Single underserved rural community, anchor institution as first real user (see `deployment_plan.md`). |
| Adoption risks | POTRAZ regulatory sandbox approval timeline; sensing-hardware import/sourcing lead times; community trust/adoption of a new connectivity option; see `risk_compliance_checklist.md` and proposal Section 4 for the full risk table. |
| Success metrics | 30 days: sensing nodes deployed and streaming real data, dashboard live with real (not simulated) readings. 60 days: constraint engine making real grant/deny decisions with zero incumbent-interference incidents. 90 days: anchor institution has measurable broadband access via an opened channel, POTRAZ has reviewed the audit log and confirmed compliance. |
